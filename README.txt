MY HIFZ — QURAN READER

Open index.html in Chrome or Edge. All 30 Juz and 547 original JPGs are included.
Keep the quran folder, index.html, style.css, pages.js and app.js together.

REPLACE IMAGES: Open Juz library, use the circular-arrow button beside a Juz, or
click Replace Juz images. Select a ZIP or multiple images. Review the sorted filenames
and confirm. The page count can change. Revision history and notes stay; previous
mark coordinates are flagged for review. Restore original scans is available.
For a complete ZIP, use Import complete Quran ZIP (folders 1–30).

PROGRESS: Mark/Erase on the image, add notes, open mistakes list, or log quarters.
ONE-CLICK TRACKING: In the reader (including fullscreen), tap Q1–Q4 or Whole Juz.
Each tap adds a new revision; Whole Juz adds all four quarters, even if some were
already logged today. The outlined quarter estimates your page position; choose the
quarter you actually completed. Tap Undo log to remove the last logging action.
The progress grid and library also allow one-click logging. Daily counts and recent
revisions update immediately. Existing browser storage and backup format are unchanged.
Progress displays 120 quarter cells and daily activity. Full screen button or F key;
left/right arrow keys turn pages. Fit page/width and zoom controls are available.

STORAGE: This is a static website; no account sync is configured. Progress and local
image replacements are stored in the browser, per device and site address. Download
progress backups regularly; keep your replacement ZIPs separately. Clearing browser
storage removes custom scans and local progress. The old site's progress format is
not guaranteed to be compatible; this website does not alter the original site.

HOSTING: Upload the CONTENTS of this folder to a GitHub repository, preserving the
quran/ folder. Enable GitHub Pages in Settings > Pages > Deploy from a branch > main
> /(root). Use GitHub Desktop or git for the large number of images. Google Sites
can embed the published GitHub Pages URL (Insert > Embed), but does not directly
host this HTML/JS folder. Fullscreen may be limited in an embed; open the direct URL.
